## 📌 Tentang Lentera Kecil
Lentera Kecil adalah sebuah platform *interactive storytelling* (novel visual ringan) berbasis web. Proyek ini memadukan kekuatan narasi teks dengan elemen visual minimalis untuk memberikan pengalaman membaca yang imersif bagi penggunanya.

### ✨ Fitur Utama
* **Branching Storylines:** Pembaca bisa menentukan pilihan di akhir bab yang akan memengaruhi kelanjutan alur cerita (*multiple endings*).
* **Dynamic Backgrounds & Transitions:** Perubahan suasana visual (warna latar belakang, animasi redup/terang) yang menyesuaikan dengan emosi cerita.
* **Save Progress State:** Fitur otomatis menyimpan halaman terakhir yang dibaca menggunakan penyimpanan browser.
* **Responsive Reading Layout:** Desain tipografi dan tata letak yang nyaman dibaca baik melalui laptop maupun *smartphone*.

### 🛠️ Tech Stack
* **Core:** JavaScript (DOM Manipulation), HTML5 Semantic Tags, CSS Transitions & Keyframes.
